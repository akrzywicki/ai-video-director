# Pool build (example script)

Hook-first narration for the sample vertical explainer (~25s at 30fps).

> Want a pool? Here's the build. Mark the yard. Dig a deep hole. Dirt chunks fly out. Drop a steel rebar cage. Spray gunite concrete. Smooth the shell. Trench pipes underground. Hook up skimmer lines. Fill with water. Fire up circulation. Arrows spin the flow. Debris sweeps away. Clean pool. Done.
